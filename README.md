# IntiLearnAI

Asistente educativo offline para zonas rurales basado en IA.

## Características

- RAG local con FAISS
- Modelos Gemma / Mistral offline
- Whisper (voz a texto)
- Coqui TTS (texto a voz)
- Streamlit + FastAPI
